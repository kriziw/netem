Topology & interfaces

Open Settings → Topology & interfaces to define the physical/virtual NIC pairs used by WAN1 and WAN2. The setup page excludes loopback, the detected management NIC and existing br-* bridge devices from the selectable WAN NIC list.

Map each WAN

For each WAN, provide:

  • Display name — human-readable label such as Primary DIA or Backup 5G.
  • Inner interface — interface facing the firewall/SD-WAN appliance.
  • Outer interface — interface facing the ISP/upstream router.

Saving topology creates br-wan1 and/or br-wan2, enslaves the selected ports and brings the bridge up.

What happens when topology is edited

When you save a changed topology, NetEm clears qdiscs and removes the old bridges first, then recreates the new mapping. It preserves the previous WAN's selected profile, quality, mode, custom impairment and bandwidth overrides where possible.

Traffic interruption: changing topology is a dataplane operation. Do not edit interface mapping during an active production-like lab test.

Startup restore controls

  • Restore WAN bridges on application startup recreates the transparent bridges after service/VM restart.
  • Restore selected WAN profiles and quality reapplies persisted shaping after the bridge exists.

Both are recommended when NetEm is used as a persistent lab appliance.

Reset appliance configuration

Reset configuration clears qdiscs, removes configured bridges and deletes config.json. Use it only when rebuilding the appliance topology from scratch.

Access profiles

Open Settings → Access Profiles to edit the nominal 100% baseline for each technology. A profile contains a name, quality behavior model, latency, jitter, packet loss and nominal download/upload bandwidth.

Quality behavior models

The quality behavior model determines how a profile deteriorates below 100%. NetEm uses staged anchor points with exponential easing rather than a straight linear multiplier. Different metrics begin degrading at different quality levels.

This is why changing a DIA circuit from 100% to 40% does more than simply make it “60% slower”: latency, jitter and loss increase sharply as the modeled circuit approaches failure.

Profile baseline vs WAN override

Editing an Access Profile changes the shared baseline. Changing nominal download/upload under WAN Links → Profile changes only that WAN and does not modify the underlying access profile. Use per-WAN overrides when two links use the same technology but have different contracted speeds.

Restore profile defaults

Restore profile defaults replaces the editable profile set with the project defaults and reapplies the active WAN profiles. This can immediately change live shaping, so treat it as an operational action rather than a harmless UI reset.
