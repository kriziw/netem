  • blackhole — bidirectional data-plane blackhole.
  • downstream_blackhole — block the direction toward the appliance.
  • upstream_blackhole — block the direction toward the upstream network.

Event history

At startup, NetEm loads up to the last 500 JSONL events from runtime/events.jsonl. In-memory history is also capped at 500 events. Persistence failures are intentionally non-fatal so inability to write history does not break the lab control path.

Current product boundaries

  • The UI currently supports two configured WAN links.
  • Live chart history is browser-resident and resets on reload; event history is persistent.
  • Latency/jitter/loss charts show injected state, not active probe measurements.
  • Vendor-specific observed SLA/path-selection integrations are roadmap items.
  • Path MTU constriction is available, but a full PMTUD blackhole mode is not yet implemented.
  • Traffic generation and PCAP replay are reserved/planned functions, not currently active.
  • The application has no built-in user authentication layer; deploy access controls appropriate to the lab environment/reverse proxy.
