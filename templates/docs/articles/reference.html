SQLite time-series retention is currently 168 hours. WAN samples are collected approximately every two seconds while the service is running.

Current boundaries

  • The UI currently supports two WAN links.
  • Active probe Automatic source follows the NetEm host route; transparent WAN ports without L3 addressing cannot independently prove appliance-side path behavior.
  • Vendor-observed SLA/path-selection integration is not yet implemented.
  • PMTUD blackhole simulation, bounded traffic generation and PCAP replay remain roadmap items.
  • Built-in authentication is not yet provided.

Read-only API routes

  • /api/v1/state — normalized current state including scenario/session/probe state.
  • /api/v1/telemetry — raw/directional cumulative counters.
  • /api/v1/history?link_id=wan1&minutes=60 — aggregated SQLite history + probe samples.
  • /api/v1/probes — configured probes and latest results.
  • /api/v1/events?limit=N — runtime events.
  • /metrics — Prometheus exposition.
