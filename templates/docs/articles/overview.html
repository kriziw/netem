Purpose of the Command Center

The Command Center is the primary operating screen. It is designed so most lab work can happen without navigating to a configuration page: watch traffic, inspect WAN health, degrade a path, inject a failure, constrain MTU, change line rate, launch a guided test or open deeper analytics.

Live path topology

Each WAN row is clickable. It shows the selected access profile, nominal bandwidth, injected latency/loss/quality, expected SLA state and measured directional throughput.

The thin flow indicator at the bottom of each WAN animates only when measured traffic is crossing that path. Faster measured traffic uses a faster animation. A red path indicates an explicit runtime fault or expected SLA failure.

WAN quick-control drawer

Click a WAN anywhere in the topology or WAN pulse cards to open the quick-control drawer. Common actions are deliberately presented before low-level packet primitives.

The quality control previews expected latency, loss and downstream capacity before Apply. Use Advanced WAN settings only when you need custom packet behavior or raw qdisc diagnostics.

WAN pulse cards

WAN pulse cards combine the current measured downstream rate with a rolling sparkline, upstream rate, latency and loss. The small delta under throughput shows how the rate changed since the previous live sample; it is a short-term activity cue rather than a long-term trend calculation.

Below the chart, bars show how full each direction is against its configured limit, followed by rate-limiter queue drops, injected loss drops and the success rate of simulated users whose traffic used that WAN.

Why experience is degraded & SD-WAN steering

These cards connect what simulated users feel to the WAN that carried their traffic and the condition on that WAN that explains it, and judge whether the appliance moves traffic off impaired WANs. See Diagnosing experience & steering.

Quick actions

The right side of the Command Center exposes outcome-oriented shortcuts such as Degrade a WAN, Fail a WAN, Unstable WAN and Capture traffic. These open the Tests workflow rather than asking you to locate the underlying implementation feature.

Live activity

The recent activity card shows a short timeline. The global Activity button opens a right-side rail that refreshes runtime events approximately every 2.5 seconds and is available from every page.

Ctrl+K command palette

Press Ctrl + K (or Command+K on macOS) to open the global command palette. It can jump to Command Center, Tests, Analytics, Sessions, Settings, Help or a specific WAN's controls.

Session awareness

If a lab session is active, the top bar shows its name and all newly written runtime events are tagged with that session ID. This lets you operate normally while preserving context for later review.

What is live

Throughput and packet-rate values come from Linux interface counters. Latency, jitter, loss and quality are the conditions NetEm is injecting, not remote active-probe measurements. The expected SLA therefore reflects the injected state. Future vendor adapters are intended to add observed appliance SLA/path-selection data alongside it.
