Purpose of Overview

Overview is the primary screen to leave open while running a test. It combines the state NetEm is injecting with measured traffic counters and recent runtime events, without exposing most configuration controls.

Top status indicators

IndicatorMeaning
WAN healthNumber of configured links whose generic expected SLA currently passes.
Active impairmentsRuntime faults such as blackholes. Saved quality degradation alone is not counted as a runtime fault.
ScenarioCurrent scenario name and stage, or Idle when none is running.
Packet captureWhether a bounded tcpdump capture is currently active.

Live path topology

The topology panel shows the appliance under test on the left, each emulated WAN in the middle and the upstream network on the right. Each WAN row displays:

  • display name and selected access profile;
  • nominal download/upload bandwidth;
  • currently injected latency, jitter and packet loss;
  • health/SLA status;
  • live measured directional throughput once at least two telemetry samples have been collected.

Use Manage WANs to open the full WAN Links control page when you need to change the path.

Live throughput chart

The Overview chart plots measured downstream traffic for each WAN. Values are derived from Linux interface byte counters sampled by the browser. The Y axis dynamically scales in Mbit/s and the X axis shows the rolling elapsed-time window.

A flat zero line is legitimate if no traffic is crossing that path. If you know traffic is flowing but the value stays at zero, use the Troubleshooting guide to compare /api/v1/telemetry with the interface counters.

WAN summary

The WAN summary distinguishes the selected access model from the current effective values. Effective down/up is the bandwidth limit NetEm intends to apply after the selected quality curve or custom values are evaluated. It is not the same as current traffic utilization.

Recent events

The timeline shows recent runtime activity such as scenarios, faults, MTU changes, capture activity and safe security-test events. Events are also persisted to runtime/events.jsonl and are available from Analytics and the API.

Status language

  • Green: path is within expected SLA and no runtime fault is active.
  • Amber: degraded quality that is still within the configured generic SLA.
  • Red: expected SLA failure or an explicit runtime fault.
Important: an expected SLA PASS/FAIL is calculated from what NetEm is injecting. It is not yet the SD-WAN appliance's own measured SLA state. Vendor adapters are designed to add that second perspective later.

Live refresh behavior

The browser polls the state and telemetry REST APIs approximately every 1.5 seconds. The rolling history currently lives in the browser, so reloading the page clears the chart history. Persistent time-series storage is a future capability; event history is already persistent.
