What WAN Links controls

WAN Links is the manual control plane for each configured circuit. The page keeps live status visible while detailed configuration opens in a right-side drawer. Use it for one-off experiments and baseline setup; use Scenarios when the test should be repeatable.

Profile tab

Access technology

Select DIA, DSL, Broadband, 4G, 5G, Satellite or any edited profile. A profile defines nominal latency, jitter, packet loss, download/upload bandwidth and the type of quality degradation curve.

Nominal line rate

Download and upload can override the profile's default capacity without switching the link to Custom mode. This is useful when the technology is correct but the actual service speed is different—for example, Broadband at 500/50 Mbit/s or DIA at 2 Gbit/s.

Reset to profile defaults clears both per-WAN rate overrides.

Quality tab

The Quality slider is a high-level way to degrade a circuit. NetEm does not change every metric linearly. Each access model has staged degradation curves so a mobile link, satellite path and DIA circuit deteriorate differently.

QualityStatus labelGeneral interpretation
90–100ExcellentNear-normal service
75–89GoodMild degradation
50–74FairNoticeable impairment
25–49PoorSevere impairment
1–24CriticalNear-unusable service
0Down100% loss, extreme delay/jitter and 1 Mbit/s floor

Manual impairment values

Latency, jitter, packet loss, download and upload can also be moved individually. As soon as you change one of these controls the WAN enters Custom mode. The values are then persisted exactly as configured rather than recalculated from the quality curve.

Move the Quality slider again to return to quality-derived mode; doing so deliberately discards the manual custom overrides.

Faults tab

Faults are transient test actions; they do not overwrite the saved access profile.

FaultBehavior
Bidirectional blackholeDrops traffic both directions while link/carrier remains up.
Downstream blackholeDrops traffic returning toward the appliance.
Upstream blackholeDrops traffic leaving the appliance toward the upstream network.
Restore normalRemoves the runtime fault and reapplies the saved WAN profile.
Scenario lock: manual faults and MTU changes are blocked while a scenario is running. Stop the scenario first so two control paths cannot fight over the same WAN.

Path MTU testing

Temporary MTU constraints are applied to the inner interface, outer interface and bridge. Preset choices include 1500, 1492, 1400, 1380, 1300 and 1200 bytes. Selecting Restore original returns the interfaces to the MTUs captured before the first change.

This is an MTU-constriction test. It is not a complete PMTUD-blackhole simulator that selectively drops oversized traffic while suppressing ICMP feedback.

Diagnostics tab

Diagnostics shows the mapped interface names, bridge, active fault and raw tc qdisc state for inner and outer sides. Use it to verify that the kernel accepted the intended impairment and bandwidth qdiscs.

Apply behavior

Apply WAN configuration saves the profile, quality/custom values and line-rate overrides, then reapplies the qdisc. The previous root qdisc is cleared first so the new state does not stack on top of stale settings.
